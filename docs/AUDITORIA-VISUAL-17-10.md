Revisando amostras visuais de dois momentos dos 24 exercícios distintos, identificamos associação incompatível com os nomes prescritos. O código passou a BLOQUEAR essas imagens. O GIF do dia apresenta um cartão explícito de referência pendente e o GIF individual inadequado é removido do output ao regenerar.

Esta revisão visual **não certifica os demais movimentos**. Eles continuam rotulados como ilustrativos e precisam de correspondência anatômica/qualidade verificada antes da versão final. Foram examinados como prioridade vários GIFs de treino, e permanecem riscos de exercícios estáticos cuja repetição de quadros sugere movimento onde não há.

## Origem preferida para substituição

GitHub serve para procurar projetos com ilustrações e **licença explícita dos arquivos**; Canva serve para desenhar o personagem e produzir cartões visuais, porém uma imagem gerada não substitui uma captura de movimento humano validada. Referências de técnica devem vir de exercício equivalente (variantes diferentes não são aceitas). Não reusar material de filmagens com direitos não demonstrados.

## Critério de release

O status `revisao_pendente` não gera GIF individual. Quando uma fonte nova for escolhida, ela exige inspeção da variação exata e das posições reais, licença permitida e atualização documental do ID no catálogo. A proteção para GIFs antigos impede republicação silenciosa.
